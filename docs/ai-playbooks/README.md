# AI Playbooks

Reusable prompts and workflows for AI-assisted development in this repository.

## What belongs here
- Prompt templates for feature delivery, bug fixes, refactors, QA, and release notes.
- Checklists for architecture, testing, and documentation updates.

## How to use
1. Pick a prompt template from this folder.
2. Customize the variables (project, scope, constraints, tests).
3. Keep outputs aligned with repository rules and domain boundaries.

## Contents
- `best-practice-prompt.md`: A full-cycle prompt template covering design → coding → testing → PR summary.
